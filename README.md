# Josh Li - Projects
Incoming Biophysics student at UCLA with research experience in nanomaterials and molecular biology. This repository contains coding projects developed for coursework, self-study, and skill-building.

## Projects: 
1. DNA Sequence Translator, Python. Command-line program that reads DNA sequences from FASTA files, converts DNA to mRNA, and translates codons into amino acids using file I-O, dictionaries, and string processing.
2. Survey Form, HTML and CSS. Semantic form built with structured input types, validation, and accessibility practices including labeled fields and fieldsets.
3. Cafe Menu, HTML and CSS. Practice project focused on responsive layout and page styling.
