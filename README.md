# Josh Li - Projects
First year Biophysics student at UCLA with research experience in nanomaterials and molecular biology. This repository contains coding projects developed for coursework, self-study, and skill-building.

## Projects
1. [DNA Sequence Translator](CLI_project/), Python. Command-line program that reads DNA sequences from FASTA files, finds open reading frames in each reading frame, translates them into proteins with the standard genetic code, and saves the results as an HTML page.
2. Survey Form, HTML and CSS. Semantic form built with structured input types, validation, and accessibility practices including labeled fields and fieldsets.
3. Cafe Menu, HTML and CSS. Practice project focused on responsive layout and page styling.
