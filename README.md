# Josh Li - Projects
Incoming Biophysics student at UCLA with research experience in nanomaterials and molecular biology. This repository contains coding projects developed for coursework, self-study, and skill-building.

## Projects

### [DNA Sequence Translator](dna-translator/) · Python
Command-line program that reads DNA sequences from FASTA files, finds open reading frames in each reading frame, translates them into proteins with the standard genetic code, and saves the results as an HTML page.

![The page the translator makes for an example mRNA: its 178-amino-acid protein, mass and position](dna-translator/example_output/screenshot.png)

### [Survey Form](survey-form/) · HTML
Semantic form built with structured input types, validation, and accessibility practices including labeled fields and fieldsets.

### [Cafe Menu](cafe-menu/) · HTML and CSS
Practice project focused on responsive layout and page styling.
