An open reading frame (ORF) runs from a start codon (AUG) to the next stop codon (UAA, UAG or UGA) in the same reading frame. The main protein is the longest ORF that ends at a stop codon; if none does, it's the longest ORF found, marked "incomplete". Forward-strand ORFs are preferred, because mRNA records are written in the forward direction.

In genomic DNA, genes are interrupted by introns that this program can't cut out, so a protein found there may be only part of the real one. For the real protein, use an mRNA record (for example a RefSeq "NM_" sequence).
