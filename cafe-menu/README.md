# Cafe Menu

A menu page for a made-up coffee shop, styled with CSS. It follows freeCodeCamp's "Learn Basic CSS by Building a
Cafe Menu" lesson.

## What it shows
- Content (`cafe_menu.html`) kept separate from style (`cafe_menu_styles.css`).
- Type, class and grouped selectors (`h1, h2`), and link states (`a:hover`, `a:visited`).
- Layout basics: a centered menu card that is 80% of the page wide but never wider than 500px (`width: 80%`,
  `max-width: 500px`, `margin-left: auto`, `margin-right: auto`), and item names and prices on one line
  (`display: inline-block` with widths of 75% and 25%).

## How to view it
Download both files into the same folder and open `cafe_menu.html` in a web browser. The images load from
freeCodeCamp's website, so you need to be online.
